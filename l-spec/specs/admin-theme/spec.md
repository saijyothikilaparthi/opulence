# admin-theme Specification

## Purpose
Updates the admin dashboard UI to match the frontend theme for a consistent user experience.

## Requirements

### Requirement: Admin dashboard matches frontend theme
The admin dashboard UI SHALL use the same CSS styles, colors, and typography as the frontend website.

#### Scenario: Viewing the admin dashboard
- **WHEN** an admin user accesses the admin dashboard
- **THEN** the dashboard is styled consistently with the frontend website
